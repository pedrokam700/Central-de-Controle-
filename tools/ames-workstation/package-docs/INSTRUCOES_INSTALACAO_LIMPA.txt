3. Conecte o Wi-Fi TAXXX_5G pelo Windows, com credenciais fornecidas pela TI.
   Uma instalacao virgem nao possui perfil salvo; este pacote nao fornece senha.

   instalara dependencias locais se faltarem e iniciara um unico agente/Chrome.

   Envie print do erro sem mostrar credenciais, token ou dados pessoais.
