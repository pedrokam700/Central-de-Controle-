## Contrato proposto antes de alterar runtime

Entrada independente `ames/agent/lab_entry.py`, invocada explicitamente por
Python `-I -S -B`, em raiz nova autorizada de nome AMES-LAB-*, stdlib somente.
Protocolo fechado stdin/stdout: status, append_fixture (fixture interna sem dados
arbitrários), shutdown. SQLite LAB com marcador de esquema/identidade sintética;
sem importar/migrar/copiar SQLite real. Nenhum listener, UI, token de posto, job,
monitor, guardian, Chrome, engine, SQL arbitrário ou recuperação automática.

Guarda de auditoria Python antes de persistir: negar rede/processos/código nativo
arbitrário, leitura/escrita fora do escopo permitido; validar links, inventário e
config exata; claim exclusivo de sessão, retenção após falha; respeitar journal
D01/D02. Falha de qualquer prova = LAB_REFUSED, sem fallback operacional.

**Limite explícito:** política de processo confiável e protocolo fechado não são
sandbox de kernel para executar código hostil. VM/conta/FS sem escritor adversário
e contenção externa continuam obrigatórios no ensaio Windows futuro. Não oferecer
endpoint para rodar Python/SQL/scripts. Esta entrada testa persistência sintética,
não reproduz o agente HTTP ou shell completo. Regressões reais #86–92 continuam
nas suítes existentes e harness independente.
